# Smart Tabs

**Browser-style project tabs for Blender.** Work on several .blend projects in one window and switch with a click.

### ⬇️ [Download the latest version](https://github.com/graphteam-dev/Smart-Tabs/releases/latest)

Free and open source (GPL) · Blender 4.2+ · Windows, macOS, Linux

## Features

**Work faster**
- Switch projects with one click or Ctrl+Tab, right in the 3D Viewport header
- No "save changes?" pop-up: edits stay in the tab (marked *) until you save
- **Save All** (Ctrl+Alt+S) and a ⚠ counter showing how many tabs are unsaved
- **Reopen Closed Tab** (Ctrl+Alt+T)
- Untitled projects are kept safe, even after a restart
- Each tab remembers its camera view and shading

**Copy between projects**
- Ctrl+C / Ctrl+V objects between .blend files, with materials, textures and node groups
- Right-click any object to copy just its **modifiers**, **materials** or **camera/light settings**

**Stay organized**
- Pin, rename, duplicate and search tabs
- Save groups of projects as sessions
- Scene tabs for files with many scenes

## Install

1. Download `Smart_Tabs_v1.0.0.zip` from the [latest release](https://github.com/graphteam-dev/Smart-Tabs/releases/latest). **Don't unzip it.**
2. In Blender: **Edit › Preferences › Get Extensions › ⌄ (top right) › Install from Disk…**
3. Choose the ZIP. The tabs appear in the 3D Viewport header. Press **N › Smart Tabs** for all options.

The full user guide (PDF) is included in the release.
